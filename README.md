# Python Language: Basics to Advanced

A structured collection of **1082 Python `.py` files** covering beginner, intermediate, and advanced topics.

## Contents
- Printing, comments, variables, data types, input and operators
- Conditionals, loops, patterns, functions and recursion
- Lists, tuples, sets, dictionaries, strings and comprehensions
- OOP, exceptions, modules, file handling and JSON/CSV
- Searching, sorting, number theory, matrices and common DSA structures
- Regular expressions, dates, SQLite, HTTP, concurrency and async
- Advanced Python features, data analysis, machine learning examples and mini-projects
- Practice templates for self-study

## Requirements
- Python 3.10+ recommended for most examples; a few examples use modern syntax such as `match/case` (Python 3.10+).
- Core examples mostly use the Python standard library.
- Optional examples clearly report missing dependencies such as NumPy, pandas, Matplotlib, or scikit-learn.

## Run an example
Open a terminal in the extracted folder and run:
```bash
python 01_Basics_Print_Comments/hello_world.py
```
On Windows, `py` can also be used:
```powershell
py 01_Basics_Print_Comments\hello_world.py
```

## Notes
- Run one file at a time; some examples request input or start a local HTTP server.
- Files in `26_Practice_Templates` are intentionally unfinished exercises with TODO markers.
- Examples are for learning. Review code before running it, especially file and network examples.
- The collection contains both completed examples and practice templates; the total file count is not the count of unique completed solutions.
